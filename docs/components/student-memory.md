# Student Memory

**Source:** `apps/student-memory`

Student Memory owns authentication, canonical-skill classification, short-term
memory, concept memory, long-term memory, misconceptions, and completed-attempt
receipts. It is also the sole Alembic owner for the shared PostgreSQL database.

For a panel demonstration, show the FastAPI contracts, Alembic revisions, and
the presentation views in the `student_memory` schema.
