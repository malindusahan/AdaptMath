# Tutor

**Source:** `apps/tutor`

The Tutor owns the live teaching workflow: request authentication, topic and
skill selection, planning, response generation, assessment, recovery, and
durable lesson checkpoints. It integrates the other three research components
without taking ownership of their scientific state.

For a panel demonstration, show `app/graph/workflow.py`, the agent directories,
`app/api/tutor.py`, and a live Demo Trace.
