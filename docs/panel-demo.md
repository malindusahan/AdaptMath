# Panel demonstration sequence

1. Introduce the four component directories and their ownership boundaries.
2. Show one independent test or diagnostic from each component.
3. Explain each component's input and output contract.
4. Start the integrated stack with `start-adaptmath-local.ps1 -FinalSKLLive`.
5. Complete a tutoring interaction and open Demo Trace.
6. Relate the trace to Tutor orchestration, memory retrieval, BKT mastery, and
   pedagogical move selection.
7. Inspect the PostgreSQL presentation views and research tables.

The presentation principle is: separate in code and scientific responsibility,
integrated during execution.
